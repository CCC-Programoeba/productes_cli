# Pràctica 1: projecte base

Llegiu [l’enunciat](../../docs/enunciats/01.md) abans de començar.
Executeu totes les ordres des d’aquesta carpeta:

```bash
dart pub get --offline
dart run bin/productes_cli.dart list
dart run bin/productes_cli.dart show ENT01
```

La base compila, però els mètodes amb TODO llancen UnimplementedError fins que els completeu. També hi ha refactoritzacions guiades en l’enunciat; no basta omplir els TODO.
